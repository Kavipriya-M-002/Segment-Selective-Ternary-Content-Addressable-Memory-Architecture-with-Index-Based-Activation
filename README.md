# Segment-Selective Ternary Content Addressable Memory Architecture with Index-Based Activation

## 🔍 Overview

This project explores an activity-aware approach to Ternary Content-Addressable Memory (TCAM) architecture, with a focus on reducing unnecessary switching activity and improving power efficiency. The design investigates selective activation within a segmented TCAM architecture to avoid unnecessary comparisons during search operations. The project was developed and functionally verified at RTL level.

## 🎯 Project Objectives

- Explore power-efficient TCAM architecture for search-intensive applications.
- Reduce unnecessary switching activity during search operations.
- Investigate selective activation to improve hardware activity efficiency.
- Evaluate functional behavior and switching activity across different design configurations.
- Reduce dynamic power consumption compared with conventional TCAM.
